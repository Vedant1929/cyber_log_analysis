# 🔐 Cybersecurity Log Analysis & Intrusion Pattern Detection (Python)

## 📌 Project Overview
This project performs cybersecurity log analysis on SSH login attempt data to identify intrusion patterns and suspicious behavior. Using Python data analysis libraries, the project extracts insights about attacking IPs, targeted usernames, attack timing patterns, and brute-force indicators.

The goal is to simulate real-world security log investigation using data analysis techniques.

---

## 🎯 Objectives

- Analyze SSH login attempt logs
- Identify most active attacking IP addresses
- Detect most targeted usernames
- Find peak attack hours and patterns
- Analyze port targeting behavior
- Detect brute-force style repeated attempts
- Generate visual security insights

---

## 🛠 Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
